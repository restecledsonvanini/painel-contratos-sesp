# Skills — Boas Práticas & Guias

Este diretório contém guias de **skills** e boas práticas recomendadas para o projeto *Centro de Inteligência Contratual — SESP/PR*.

Cada subpasta descreve práticas, checklists e exemplos aplicáveis ao projeto (frontend, acessibilidade, testes, CI/CD, etc.). Use os arquivos como referência técnica e como base para pull requests e documentação.

## Estrutura
- `index.json` — metadados das skills
- `react/skill.md` — React 19+ e TypeScript
- `tailwind/skill.md` — Tailwind v4.1 e theming
- `lucid-react/skill.md` — padrões de componentes acessíveis
- `accessibility/skill.md` — recomendações a11y
- `testing/skill.md` — unit / e2e / storybook
- `ci-cd/skill.md` — pipelines e checks
- `banco-sqlite/skill.md` — database implementation plan
- `task-plan/skill.md` — premisses and IA Agent vs. user in development

---

> Para atualizar ou adicionar uma skill, crie uma nova pasta e adicione um `skill.md` com exemplos e checklists. Pull requests com melhorias são bem-vindos.
