# CI/CD & Observability — Padrões

Automatize qualidade e deploys com pipelines confiáveis.

- GitHub Actions: pipelines para lint, typecheck, unit tests, storybook build e e2e.
- Gates: PR checks obrigatórios, coverage thresholds e reviews.
- Observability: Sentry para erros, métricas de uso e logs para auditoria.
- Release: versionamento semântico e changelog gerado automaticamente.

Checklist:
- [ ] Pipelines com checks claros
- [ ] Alertas para falhas críticas em produção
- [ ] Documentação de runbooks para incidents
